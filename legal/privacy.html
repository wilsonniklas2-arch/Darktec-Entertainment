2. Hosting and server log data

This website is published using GitHub Pages, a hosting service provided by GitHub, Inc. 3. External fonts and images

The source currently loads web fonts from Google Fonts and photographs from Unsplash image URLs. When a page containing these resources loads, the visitor's browser may connect directly to those providers and disclose technical data such as IP address and browser information. Consider self-hosting licensed fonts and images to reduce third-party requests. Verify the relevant providers' privacy terms, legal basis and any international transfers.

4. Interactive map

The Festival World Map uses the Leaflet library from the unpkg CDN and map tiles from OpenStreetMap tile servers. Loading and using the map can cause requests to those third parties, including transmission of technical connection data and map tile requests. Review the current OpenStreetMap tile usage policy and CDN privacy information; consider self-hosting Leaflet and using a suitable tile provider with documented terms.

5. Contact by email

Links on this website may open the visitor's email application addressed to DARKTEC. If a visitor sends an email, the sender's address, message content and any personal information included are processed to respond to the enquiry and manage follow-up. Do not send sensitive information. Define a retention period and legal basis appropriate to the actual enquiry and any resulting contract.

6. Language translation

If a visitor chooses a machine-translation option, the browser is redirected to Google Translate. This is an optional external service and is not loaded automatically by the website. Google may process technical data and the requested page address. Review Google's applicable privacy terms and confirm the legal basis and international-transfer position before enabling this feature for public launch.

The website should be checked in a browser to identify all cookies, local storage, pixels and other access to terminal equipment.
